## A shared update

An iterative computation applies the same update rule several times. Let $h_t$ be a state, $x$ an input, and $f_\theta$ an update function with shared parameters:

$$
h_{t+1} = f_\theta(h_t, x), \qquad t = 0, \ldots, T-1.
$$

This notation describes repeated computation. It does not, by itself, imply improved reasoning or better efficiency. Universal Transformers is one relevant reading reference [1](#ref-universal-transformers).

## A minimal code example

The following TypeScript function illustrates repetition only; it is not a transformer implementation.

```ts
function iterate<T>(initial: T, update: (state: T) => T, steps: number): T {
  let state = initial;
  for (let t = 0; t < steps; t++) state = update(state);
  return state;
}

const result = iterate(1, x => x * 2, 3); // 8
```
