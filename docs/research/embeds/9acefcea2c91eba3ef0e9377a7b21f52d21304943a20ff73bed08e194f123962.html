1. 1
    固定论文、代码、配置路径、文件清单及其顺序
    当前 tokenizer 脚本指向未随该 tree 提供的 cooldown YAML；不冒充历史 launcher
  2. 2
    对每个来源枚举可读 parquet 文件
    记录文件 token 数、文档数、权重与 keep_all 元数据
  3. 3
    计算 m=⌊w⌋m=\lfloor w\rfloor
    w 是文件复用倍率，不是归一化 token 概率
  4. 4
    计算 r=round((w−m)n)r=\operatorname{round}((w-m)n)
    Python 的 round 使用 ties-to-even；小正权重可能选零文件
  5. 5
    复制整份文件列表 m 次，再无放回抽 r 个文件
    保留重复出现身份；随机抽样依赖调用前 RNG 状态和清单次序
  6. 6
    合并来源列表，按固定 seed 打乱后分给数据准备任务
    源脚本在按任务 stride 分片前打乱文件列表
  7. 7
    读取文本、编码，并附上每个文档的 keep_all
    本算法省略真实 tokenizer、Arrow 与文件读写
  8. 8
    按源脚本设置打乱文档行
    随后 map 按实际文档 batch 边界运行
  9. 9
    对每个 map batch 初始化 C 为空、旧标志为 false
    源函数局部状态不跨 map batch 保留
  10. 10
    依次读取完整文档 z 及其标志
    下面的长度检查发生在追加 z 之前
  11. 11
    若 |C|≥S+1|C|\ge S+1：
    S 是训练输入长度；存储块长 S+1
  12. 12
    若旧标志为 true：
    该标志属于此前最后追加的文档
  13. 13
    只要 C 仍含完整块，就输出首 S+1 个 token
    每次从 C 移除这些 token，保留尚未满块的尾部
  14. 14
    否则：输出首个完整块，再清空 C
    其余尾部在这个分支被丢弃
  15. 15
    将当前文档 z 完整追加到 C
    不是逐 token 持续输出的普通串流切块器
  16. 16
    把旧标志改为当前文档的 keep_all
    下一篇文档进入循环时才再次检查长度
  17. 17
    文档循环结束时，单独记录 C 中未输出的 token
    固定函数没有最终 flush；即使 C 已满块也不会自动输出
  18. 18
    记录来源级保留量、丢弃量和重复出现量
    keep_all 只改变指定切块分支，不是每个 token 都保留的证明
  19. 19
    把每个存储块转为 x=首 S 位、y=后 S 位
    模型接收已移位目标；不要再次 shift
  20. 20
    按实际代码区分块级 train／val 划分与问题级留出
    不从随机行划分推断原始文档身份互斥
  21. 21
    返回块清单、目标计数、来源及全部版本信息
    固定代码的函数语义已核；历史语料实物及完整 launcher 未取得
